# نرم‌افزار فاکتور سنگبری

پیاده‌سازی: **C# (.NET 8 WinForms) + SQLite**

## ساختار پروژه

```
SangbariInvoice.sln
SangbariInvoice/
  SangbariInvoice.csproj
  Program.cs
  Data/DatabaseHelper.cs              -> ساخت جداول و تمام عملیات دیتابیس
  Models/Invoice.cs                   -> مدل جدول Invoices
  Models/InvoiceItem.cs               -> مدل جدول InvoiceItems + فرمول محاسبه
  Helpers/PersianDateHelper.cs        -> محاسبات تقویم شمسی (سال/ماه/روز، تعداد روزهای ماه و...)
  Helpers/ExcelExportHelper.cs        -> خروجی اکسل (لیست فاکتورها و تک‌فاکتور) با ClosedXML
  Helpers/InvoicePrinter.cs           -> چاپ/پیش‌نمایش فاکتور با PrintDocument
  Controls/PersianDatePicker.cs       -> کنترل انتخاب تاریخ (تکست‌باکس + دکمه تقویم)
  Controls/PersianCalendarPopup.cs    -> پنجره تقویم شمسی گرافیکی
  Forms/MainForm.cs                   -> لیست فاکتورها، جستجو، جدید/ویرایش/حذف/خروجی اکسل
  Forms/InvoiceForm.cs                -> فرم ثبت/ویرایش فاکتور، چاپ، خروجی اکسل تک‌فاکتور
```

## پیش‌نیاز اجرا

1. ویندوز + [.NET 8 SDK](https://dotnet.microsoft.com/download) نصب باشد.
2. Visual Studio 2022 (نسخه Community رایگان کافی است) یا فقط دستور خط.

## نحوه اجرا

### با Visual Studio
1. فایل `SangbariInvoice.sln` را باز کنید.
2. Visual Studio به‌طور خودکار پکیج NuGet مربوط به SQLite (`Microsoft.Data.Sqlite`) را نصب می‌کند.
3. F5 را بزنید.

### با خط فرمان
```
cd SangbariInvoice
dotnet restore
dotnet run
```

فایل دیتابیس (`invoices.db`) در همان پوشه‌ی اجرای برنامه به‌صورت خودکار ساخته می‌شود؛ نیازی به نصب هیچ سروری نیست.

## نکات مهم پیاده‌سازی

- **دو جدول**: `Invoices` (اطلاعات مشتری + سرفاکتور) و `InvoiceItems` (ردیف‌های کالا) — دقیقاً طبق ساختار توافق‌شده.
- **جستجوی خودکار مشتری**: با تایپ موبایل در فرم فاکتور و خروج از آن فیلد (Leave event)، آخرین فاکتور ثبت‌شده با همان موبایل پیدا می‌شود و نام/آدرس/تلفن/معرف به‌صورت خودکار پر می‌شوند (بدون بازنویسی فیلدهایی که کاربر از قبل دستی پر کرده).
- **فرمول ابزار**: اگر تیک «ابزار» بخورد، ستون عرض غیرفعال و مقدارش صفر می‌شود؛ `مترمربع = طول × تعداد`. در غیر این صورت `مترمربع = عرض × طول × تعداد`.
- **مجموع هر ردیف**: `مجموع = مترمربع × فی` (محاسبه لحظه‌ای هنگام تایپ).
- **جمع کل فاکتور**: مجموع تمام ردیف‌ها.
- **مانده حساب**: `جمع کل − وجه دریافتی` (وجه دریافتی فقط یک‌بار برای کل فاکتور وارد می‌شود، نه هر ردیف).
- **تاریخ‌ها**: با `System.Globalization.PersianCalendar` داخلی دات‌نت به‌صورت شمسی (فرمت 1403/05/28) نمایش داده می‌شوند؛ نیازی به کتابخانه جانبی نیست.

## ویژگی‌های اضافه‌شده در این نسخه

### ۱. انتخاب تاریخ به‌صورت گرافیکی (نه تایپی)
- تاریخ فاکتور، تاریخ دریافت وجه (در `InvoiceForm`) و تاریخ هر ردیف کالا (در جدول اقلام) همگی با کلیک روی فیلد، یک تقویم شمسی گرافیکی (`PersianCalendarPopup`) باز می‌کنند.
- تقویم بر اساس `System.Globalization.PersianCalendar` محاسبه می‌شود (کبیسه/عادی بودن سال به‌درستی لحاظ می‌شود)، بدون نیاز به کتابخانه جانبی.
- کاربر دیگر امکان تایپ آزاد تاریخ را ندارد؛ این از خطای فرمت تاریخ جلوگیری می‌کند.

### ۲. خروجی اکسل
- **در `MainForm`**: دکمه «خروجی اکسل» کل لیست فاکتورهای نمایش داده‌شده (با اعمال فیلتر جستجو، در صورت وجود) را در یک فایل xlsx ذخیره می‌کند.
- **در `InvoiceForm`**: دکمه «خروجی اکسل» همان فاکتور بازشده را (با تمام ردیف‌های کالا و جمع/مانده) در یک فایل xlsx جداگانه ذخیره می‌کند.
- پیاده‌سازی با کتابخانه رایگان و متن‌باز **ClosedXML** (به‌صورت خودکار هنگام build از طریق NuGet نصب می‌شود).

### ۳. چاپ فاکتور
- دکمه «چاپ فاکتور» در `InvoiceForm` یک گزارش چاپی شامل اطلاعات مشتری، جدول اقلام (تاریخ، قطر، شرح سنگ، تعداد، ابزار، عرض، طول، مترمربع، فی، مجموع) و بخش جمع کل/دریافتی/مانده حساب را در یک پنجره پیش‌نمایش چاپ (`PrintPreviewDialog`) باز می‌کند.
- اگر تعداد ردیف‌های فاکتور زیاد باشد و در یک صفحه جا نشود، به‌صورت خودکار صفحه‌بندی (چند صفحه‌ای) انجام می‌شود.
- پیاده‌سازی با `System.Drawing.Printing` (داخلی دات‌نت، بدون کتابخانه جانبی)، پس مستقیماً به هر پرینتر نصب‌شده روی ویندوز قابل ارسال است.

## نکاتی برای توسعه بعدی (اختیاری)

- طراحی چاپ فاکتور را می‌توان با افزودن لوگوی کارخانه یا تغییر فونت/چیدمان شخصی‌سازی کرد (در `InvoicePrinter.cs`).
- افزودن Backup خودکار روزانه از فایل `invoices.db`.
- در صورت نیاز چندکاربره شدن (چند کامپیوتر همزمان)، تعویض SQLite با SQL Server Express با تغییر کم در `DatabaseHelper.cs`.
